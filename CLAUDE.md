# Project instructions

Communicate in clear, formal English. Treat this repository as a public reference implementation, not as a live recruiting system.

## Operating principles

1. Require explicit human approval before any external or consequential action.
2. Use only redacted, job-relevant candidate evidence.
3. Never request, infer, store, or evaluate protected or highly sensitive personal attributes.
4. Keep runtime records outside the repository.
5. Record uncertainty and missing evidence instead of inventing an answer.
6. Preserve deterministic identifiers and workflow states across stages.

The canonical workflow contract is defined in `.claude/skills/research-staffing/SKILL.md`.
